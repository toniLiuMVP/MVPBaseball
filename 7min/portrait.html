七分鐘 › 做大頭照

七分鐘學會製作大頭照並匯入遊戲

把一張照片放進遊戲，變成球員資料頁上那張臉。先匯出一張現成的當範本，照著它的尺寸做，成功率最高。

前置

  • 已安裝的 MVP Baseball 2005
  • Python 3
  • 任何能存 PNG 的繪圖軟體
  • 下載 mvp_swap_portrait.py

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

⚠️ 先看你這一份換不換得了：剛安裝好的原版換不了

這支腳本只吃 DXT3 格式的大頭照。本站在三份剛安裝好的原版 （英文版、中文版、PK 版）上各量一次，portrait.big 都是 104.2 MB、2,393 個項目，那 2,391 張圖全部是 ARGB32（代號 0x7D）128×128， 一張 DXT3 都沒有，第 2 步就會停下來。

換得了的是已經被模組換成 DXT3 的封裝檔（本站測試機那份是 253.6 MB、7,544 個項目， 其中 5,250 張 DXT3 256×256）。一行分辨：

Windows:

python mvp_swap_portrait.py "〔你的遊戲資料夾〕" --info

Mac / Linux:

python3 mvp_swap_portrait.py "〔你的遊戲資料夾〕" --info

印出 項目數 2393 就是剛安裝好的原版，這一課目前做不了 —— ARGB32 的寫回還沒做。完整說明看換球員大頭照那一課。

👉 你要做的事

1

查出你要換的那位球員，大頭照是幾號。

⚠️ 名冊裡是英文拼法，打中文查不到。這裡用陳金鋒當例子 —— 他在原版遊戲裡就叫 Chin-Feng Chen，2005 年他真的在道奇隊（不過遊戲的原版名冊把他放在小聯盟的 Las Vegas 51s，不在道奇的大聯盟名單裡）。EA 給了他一張專屬大頭照 —— 原版 portrait.big 裡的 1598.fsh。曹錦輝是 Chin-Hui Tsao，他也有一張（2463.fsh）。（2026-09-05 訂正：這裡原本寫「EA 還給了他一張專屬臉」，那是錯的 —— 原版名冊裡他的臉皮欄位是 906，而本站的分級是 901 以上都算通用臉；專屬的是大頭照，不是臉皮。）
（王建民 2005 年才上大聯盟，沒趕上這款遊戲，所以查不到他。）

Windows:

python mvp_swap_portrait.py "〔你的遊戲資料夾〕" --find Chin-Feng

Mac / Linux:

python3 mvp_swap_portrait.py "〔你的遊戲資料夾〕" --find Chin-Feng
2

把那一張匯出來當範本。

Windows:

python mvp_swap_portrait.py "〔你的遊戲資料夾〕" --export 1234 old.png

Mac / Linux:

python3 mvp_swap_portrait.py "〔你的遊戲資料夾〕" --export 1234 old.png

編號換成上一步查到的。匯出來的就是遊戲裡現在那一張。

3

用繪圖軟體改。

⚠ 尺寸絕對不能改

新圖的寬高必須跟匯出來的那張完全一樣。腳本不會幫你縮放 —— 不一樣就直接拒絕，這是刻意的：幫你猜尺寸只會把圖弄糊，而且你不會知道。

最穩的做法：直接在匯出的那張上面貼你的照片，存成新檔。

4

先預覽，再寫入。

Windows:

python mvp_swap_portrait.py "〔你的遊戲資料夾〕" --import 1234 mine.png

Mac / Linux:

python3 mvp_swap_portrait.py "〔你的遊戲資料夾〕" --import 1234 mine.png

確認沒問題之後，同一行後面加 --apply。

✅ 怎麼知道成功了

  • 匯出的 PNG 打得開，而且看得出是遊戲裡那張臉
  • 匯入預覽沒有報尺寸錯誤
  • 加 --apply 後有成功訊息
  • 進遊戲看那位球員的資料頁

❌ 出錯處理

症狀怎麼辦
說是 ARGB32 格式，只處理 DXT3你這一份還是剛安裝好的原版，這一課換不了，看上面那張卡
說尺寸不對用匯出來的那張當底圖，不要自己開新檔
存出來的 PNG 匯不進去存檔時選 PNG，不要選其他格式;有些軟體預設會存成索引色
換錯人了--restore 還原，重來

想弄懂為什麼

  • 換球員大頭照 —— 完整版
  • 大頭照 portrait.big —— 2,391 張全是同一種格式
  • 圖片的像素怎麼排
