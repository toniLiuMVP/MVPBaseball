七分鐘 › 做球衣

七分鐘學會製作球衣並匯入遊戲

球衣是這個遊戲最多人做的東西。七分鐘做完的版本是：拿一套現成的球衣包，安全地裝進去。

⏱ 七分鐘怎麼分配

做什麼分鐘
把球衣包解壓縮到一個資料夾1
清點：看它到底要動哪些檔2
預覽安裝1
真的安裝1
進遊戲確認2

前置

  • 已安裝的 MVP Baseball 2005
  • Python 3
  • 一套球衣包(本站不提供)
  • 硬碟留 1.2 GB 以上（要動的封裝檔同時會有備份與工作複本兩份；剛安裝好的原版三個封裝檔兩份只要 370 MB，疊過模組的會大很多）
  • 下載 mvp_install_uniform.py。下載的檔會在「下載」資料夾：打開檔案總管左邊的「下載」，點一下最上面的網址列，把字刪掉改打 cmd 按 Enter，後面的指令都在開出來的這個視窗打（Mac 開終端機先打 cd ~/Downloads）

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。

怎麼整包複製、紀錄（王朝、名單、設定）放在哪、找不到怎麼找： 看備份與還原 SOP 的「整包複製」。

👉 你要做的事

1

先清點。裝之前先知道它要動什麼。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --scan "〔球衣包資料夾〕"

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --scan "〔球衣包資料夾〕"

這一步完全不動任何檔案，只是把球衣包裡有什麼列給你看。

2

預覽安裝。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕"

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕"
3

確認後真的裝。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕" --apply

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕" --apply

它會先備份這一次真的會動到的那幾個封裝檔再動手 —— 這套球衣沒碰到的那個就不會複製，畫面上會印出它備份了哪幾個。

✅ 怎麼知道成功了

  • 清點列出的檔案數跟球衣包裡的對得起來
  • 安裝後有印出備份訊息
  • 進遊戲看那支球隊的球衣

❌ 出錯處理

症狀怎麼辦
can't open file '…mvp_*.py' 命令視窗跟腳本不在同一個資料夾。 打開放著那個 .py 的資料夾（剛下載的話就是「下載」），在網址列打 cmd 按 Enter，用新開的視窗再跑一次（Mac 用 cd 切過去，例如 cd ~/Downloads）。 還是一樣的話，是檔名對不上：瀏覽器可能在檔名後面加了 (1)，把它改成跟指令裡一模一樣
清點說找不到球衣檔球衣包解壓縮後可能多包了一層資料夾。指到真正有檔案的那一層
裝完球衣沒變有些球衣要配合名冊裡的球隊編號。先確認你裝的是不是那支隊
遊戲當掉--restore 把有備份的那幾個封裝檔還原
停下來了:作業系統不讓我讀寫這個檔常見原因是硬碟空間不夠、遊戲裝在 Program Files 這種要系統管理員權限的位置、檔案被設成唯讀，或外接碟被拔掉。看它最後印的那一段：寫「你的遊戲檔一個位元組都沒有動,不必 --restore。」就不要還原；寫的是「封裝檔已經換過了。要退回去:」才還原 —— Windows 打 python mvp_install_uniform.py "〔你的遊戲資料夾〕" --restore，Mac / Linux 把開頭換成 python3。它自己印出來的那一行開頭一律是 python3，Windows 不要照抄
