七分鐘 › 做球衣

七分鐘學會製作球衣並匯入遊戲

球衣是這個遊戲最多人做的東西。七分鐘做完的版本是：拿一套現成的球衣包，安全地裝進去。

⏱ 七分鐘怎麼分配

做什麼分鐘
把球衣包解壓縮到一個資料夾1
清點：看它到底要動哪些檔2
預覽安裝1
真的安裝1
進遊戲確認2

前置

  • 已安裝的 MVP Baseball 2005
  • Python 3
  • 一套球衣包(本站不提供)
  • 下載 mvp_install_uniform.py

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

👉 你要做的事

1

先清點。裝之前先知道它要動什麼。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --scan "〔球衣包資料夾〕"

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --scan "〔球衣包資料夾〕"

這一步完全不動任何檔案，只是把球衣包裡有什麼列給你看。

2

預覽安裝。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕"

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕"
3

確認後真的裝。

Windows:

python mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕" --apply

Mac / Linux:

python3 mvp_install_uniform.py "〔你的遊戲資料夾〕" --install "〔球衣包資料夾〕" --apply

它會先備份這一次真的會動到的那幾個封裝檔再動手 —— 這套球衣沒碰到的那個就不會複製，畫面上會印出它備份了哪幾個。

✅ 怎麼知道成功了

  • 清點列出的檔案數跟球衣包裡的對得起來
  • 安裝後有印出備份訊息
  • 進遊戲看那支球隊的球衣

❌ 出錯處理

症狀怎麼辦
清點說找不到球衣檔球衣包解壓縮後可能多包了一層資料夾。指到真正有檔案的那一層
裝完球衣沒變有些球衣要配合名冊裡的球隊編號。先確認你裝的是不是那支隊
遊戲當掉--restore 把有備份的那幾個封裝檔還原
