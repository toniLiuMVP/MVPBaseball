七分鐘改一位球員的跑壘速度

下課時間做得完的一件事：把某位球員的跑壘速度改掉。
⚠️ 這一堂不是「編一整份名冊」 —— 加新球員、改名字、改背號、改球隊，本站目前都沒有教：名冊是 EA 的私有格式，本站只驗到 speed 這一欄「改了會生效、而且不會弄壞別的欄位」。本站的腳本一律「先預覽、加 --apply 才真的寫」，而且會自動備份。

⏱ 七分鐘怎麼分配

做什麼分鐘
找到球員、看現在的數字2
決定要改成多少1
預覽1
真的寫入1
進遊戲確認2

前置

  • 已安裝的 MVP Baseball 2005
  • 電腦裝了 Python 3.7 以上(不會裝看這堂)
  • 下載 mvp_edit_speed.py

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

👉 你要做的事

1

先查這位球員現在的速度是多少。

把「你的遊戲資料夾」換成你自己的路徑(可以直接把資料夾拖進終端機視窗):

⚠️ 名冊裡是英文拼法，打中文查不到。這裡用陳金鋒當例子 —— 他在原版遊戲裡就叫 Chin-Feng Chen，2005 年他真的在道奇隊（不過遊戲的原版名冊把他放在小聯盟的 Las Vegas 51s，不在道奇的大聯盟名單裡）。曹錦輝是 Chin-Hui Tsao。
（王建民 2005 年才上大聯盟，沒趕上這款遊戲，所以查不到他。）
（2026-09-05 訂正：這裡原本寫「EA 還給了他一張專屬臉」，那是把本站測試機的數字當成原版。兩份剛安裝好的原版量到陳金鋒的臉皮編號都是 906 —— 901 以上是通用臉，那一份裡有 126 位球員共用它。他在台灣模組裡的那張專屬臉是社群做的，見2008 年那份名冊。）

Windows:

python mvp_edit_speed.py "〔你的遊戲資料夾〕" --find Chin-Feng

Mac / Linux:

python3 mvp_edit_speed.py "〔你的遊戲資料夾〕" --find Chin-Feng

名字打一部分就好，它會把符合的都列出來。

2

決定新的數字。

速度是 0 到 99。改之前先想清楚要多少 —— 這一步不用電腦，但它是整件事裡唯一需要你判斷的地方。

3

預覽。這一步不會動到任何檔案。

Windows:

python mvp_edit_speed.py "〔你的遊戲資料夾〕" --set Chin-Feng 75

Mac / Linux:

python3 mvp_edit_speed.py "〔你的遊戲資料夾〕" --set Chin-Feng 75

它會印出「原本多少 → 要改成多少」。看清楚再往下。

4

確認沒問題，加 --apply 真的寫進去。

Windows:

python mvp_edit_speed.py "〔你的遊戲資料夾〕" --set Chin-Feng 75 --apply

Mac / Linux:

python3 mvp_edit_speed.py "〔你的遊戲資料夾〕" --set Chin-Feng 75 --apply

第一次寫入時它會自己備份原檔。

✅ 怎麼知道成功了

  • 預覽印出的「原本 → 改成」兩個數字是你要的
  • 加了 --apply 之後有印出成功訊息
  • 再跑一次 --find，顯示的已經是新數字
  • 進遊戲看那位球員的能力表

❌ 出錯處理

症狀怎麼辦
找不到球員名字換一種寫法，或只打兩個字。名冊裡的寫法不一定跟你想的一樣
說找不到 attrib.dat路徑指到的不是遊戲資料夾。它底下要有 data 這個子資料夾
改完遊戲怪怪的跑 --restore 還原。⚠️ 它退回去的是第一次 --apply 之前那一整份名冊 —— 你在那之後用把一位球員改成你想要的球員或把真實成績換算成遊戲裡的能力值改同一個 attrib.dat 的修改，會一起被退掉

⚠️ 這一課到哪裡為止

本站只把 speed 這一欄驗到「改了會生效、而且不會弄壞別的欄位」。其他能力欄位本站量過但沒有驗到同樣的程度，所以腳本不開放寫。這是刻意的，不是還沒做完。

想弄懂為什麼

  • 修改球員跑壘速度 —— 這一欄是怎麼找出來的
  • 球員資料檔全欄位清單
  • 備份與還原 SOP
