七分鐘 › 應援曲

七分鐘學會製作應援曲並匯入遊戲

讓某位球員上場時放你要的應援曲。七分鐘做得完的是把遊戲裡現成的某一首，指給另一位球員 ——不需要任何音訊工具。

⏱ 七分鐘怎麼分配

做什麼分鐘
列出現有的應援曲2
挑一首1
指給你的球員2
進遊戲確認2

前置

  • 已安裝的 MVP Baseball 2005
  • Python 3
  • 下載 mvp_swap_chant.py。下載的檔會在「下載」資料夾：打開檔案總管左邊的「下載」，點一下最上面的網址列，把字刪掉改打 cmd 按 Enter，後面的指令都在開出來的這個視窗打（Mac 開終端機先打 cd ~/Downloads）

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。

怎麼整包複製、紀錄（王朝、名單、設定）放在哪、找不到怎麼找： 看備份與還原 SOP 的「整包複製」。

👉 你要做的事

1

先看遊戲裡有哪些球員專屬應援曲。

⚠️ 名冊裡是英文拼法，打中文查不到。這裡用陳金鋒當例子 —— 他在原版遊戲裡就叫 Chin-Feng Chen，2005 年他真的在道奇隊（不過遊戲的原版名冊把他放在小聯盟的 Las Vegas 51s，不在道奇的大聯盟名單裡）。EA 給了他一張專屬大頭照 —— 原版 portrait.big 裡的 1598.fsh。曹錦輝是 Chin-Hui Tsao，他也有一張（2463.fsh）。（2026-09-05 訂正：這裡原本寫「EA 還給了他一張專屬臉」，那是錯的 —— 原版名冊裡他的臉皮欄位是 906，而本站的分級是 901 以上都算通用臉；專屬的是大頭照，不是臉皮。）
（王建民 2005 年才上大聯盟，沒趕上這款遊戲，所以查不到他。）

Windows:

python mvp_swap_chant.py "〔你的遊戲資料夾〕" --list

Mac / Linux:

python3 mvp_swap_chant.py "〔你的遊戲資料夾〕" --list
2

挑一首，把它指給你要的球員。

Windows:

python mvp_swap_chant.py "〔你的遊戲資料夾〕" --give Chin-Feng 0004

Mac / Linux:

python3 mvp_swap_chant.py "〔你的遊戲資料夾〕" --give Chin-Feng 0004

先看預覽，確認之後加 --apply。

✅ 怎麼知道成功了

  • --list 印得出應援曲清單
  • 預覽顯示的「哪位球員 ← 哪一首」是對的
  • 進遊戲讓那位球員上場打擊

❌ 出錯處理

症狀怎麼辦
can't open file '…mvp_*.py' 命令視窗跟腳本不在同一個資料夾。 打開放著那個 .py 的資料夾（剛下載的話就是「下載」），在網址列打 cmd 按 Enter，用新開的視窗再跑一次（Mac 用 cd 切過去，例如 cd ~/Downloads）。 還是一樣的話，是檔名對不上：瀏覽器可能在檔名後面加了 (1)，把它改成跟指令裡一模一樣
清單是空的原版本來就有 57 組（三份安裝量到的號碼集合完全相同），所以不是「沒裝模組」；比較可能是索引檔 spch_cht.txt 缺了或被別的工具改過，先照〈備份與還原 SOP〉那一課把它從你的整包備份拿回來
指定的編號不存在照 --list 印出來的編號填
遊戲裡沒聲音確認遊戲設定裡的音效沒被關掉

⚠️ 這一課到哪裡為止

要放你自己的音樂，得先把它轉成 EA 的音訊格式。這一格本站後來解開了一半：實測應援曲那個檔走的是編碼器 2（--info 報「2 聲道 · 24000 Hz · 103 段」），正是換掉遊戲的聲音那支腳本認得的三種之一。但本站在測試機上逐段跑過那 103 段，只有 40 段寫得回去；其餘 63 段有區塊切不出相位，腳本會明說拒絕寫入，不會硬塞一段對不齊的聲音進去。所以七分鐘這條路線仍然只做「把現成的指給別人」，要換成自己的歌請走那一課，並先確認你要蓋的那一段沒有被拒絕。

還有一件事值得記：每首應援曲的格子大小是固定的，你的錄音比較短會被補靜音、比較長會被切掉（腳本會先把這件事印出來）。（2026-09-05 訂正：這裡原本還寫著「遊戲裡會爆音」，以及「當年的建議是做成 6 到 8 秒並加淡入淡出」。那兩句本站找不到出處、也沒有實測過，已經拿掉。）

⚠️ 這一頁原本寫的是「本站的腳本做不到（理由同語音那一堂）」。那句話已經失效——語音那一堂的編碼器後來寫出來了，這裡把轉指改成本頁自己量到的結果。
