七分鐘 › 轉播畫面

七分鐘學會修改轉播檔並匯入遊戲

比賽畫面上那些東西 —— 記分板、球數燈、跑壘者速度條 ——全都寫在一種叫版面檔的純文字腳本裡。七分鐘做得完的是：把某一個元素關掉。

⏱ 七分鐘怎麼分配

做什麼分鐘
列出比賽畫面有哪些版面檔1
找到你要關的那個元素3
關掉1
進遊戲確認2

前置

  • 已安裝的 MVP Baseball 2005
  • Python 3.7 以上
  • 下載 mvp_fel_toolkit.py

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

👉 你要做的事

1

看比賽畫面裡有哪些版面檔。

Windows:

python mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --list

Mac / Linux:

python3 mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --list
2

用關鍵字找你要的元素。

Windows:

python mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --find SPEED

Mac / Linux:

python3 mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --find SPEED

元素名稱通常是全大寫英文。

3

把它關掉。

Windows:

python mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --toggle 〔版面檔〕 〔元素名〕 off

Mac / Linux:

python3 mvp_fel_toolkit.py "〔你的遊戲資料夾〕" --toggle 〔版面檔〕 〔元素名〕 off

先預覽，確認後加 --apply。

✅ 怎麼知道成功了

  • --find 找得到那個元素
  • 預覽把那幾行印成「開 → 關」
  • 進遊戲那個東西不見了

❌ 出錯處理

症狀怎麼辦
找不到元素關鍵字換英文、換全大寫。也可以用 --show 把版面檔印出來慢慢找（預設只印前 80 行，要看完整份加 --lines 9999）
關了還在你關到父群組了。遊戲執行時會把群組開關蓋回去 —— 要關就關那個元素自己那一行
遊戲當掉或畫面亂掉--restore 還原

⚠️ 這一課到哪裡為止

七分鐘只做一件事：把一個元素關掉。 這支工具能動的只有版面檔裡「顯示開關」那一欄 —— 座標、顏色、字型、文字內容它都改不了，搬位置與改字都不在這七分鐘裡。

⚠ 三條會弄壞檔案的鐵律

  1. 存回封裝檔一律用附加模式。「全部讀出來再重新打包」會讓檔案縮水，因為裡面可能有大量目錄表指不到的舊資料。
  2. 群組開關會被遊戲蓋掉。要關單一元素，改它自己那一行。
  3. 版面檔全部是 CRLF 換行。用編輯器統一成 LF 會讓檔案壞掉。

本站的腳本已經幫你守住這三條。手動改的話要自己注意。
