七分鐘調好你的執行檔

把 mvp2005.exe 上的六個旋鈕一次調好： 記憶體池（中文版配大球場不再跳出）、大位址、解析度， 以及三個把檔頭修正確的項目。全程先預覽、再寫入、隨時可還原。

⏱ 七分鐘怎麼分配

做什麼分鐘
備份整個遊戲資料夾2
看你那顆現在什麼狀態（唯讀）1
兩支腳本各跑一次預覽2
加 --apply 真的寫1

前置

  • 已安裝的 MVP Baseball 2005，而且現在打得開
  • Python 3.7 以上
  • 兩支腳本：mvp_exe_pe.py 與 mvp_modernize.py

⛔ 這一頁不碰保護措施

你那顆執行檔能不能改，是你跟你自己買的那張光碟之間的事。 本站不提供、不教學、不連結任何相關資訊。 這一頁從「你手上已經有一顆打得開遊戲的執行檔」開始講。

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

👉 你要做的事

步驟 1：先看你那顆現在什麼狀態。這一步不會動到任何檔案。

Windows:

python mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe"

Mac / Linux:

python3 mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe"

步驟 2：三個檔頭層面的項目，先預覽（還是不會寫入）。 你只要下兩個參數，第三個「檔頭檢查碼」腳本會自己跟著重算。

Windows:

python mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe" --iat --sections

Mac / Linux:

python3 mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe" --iat --sections

步驟 3：看過計畫沒問題，加 --apply 真的寫。

Windows:

python mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe" --iat --sections --apply

Mac / Linux:

python3 mvp_exe_pe.py "〔你的遊戲資料夾〕/mvp2005.exe" --iat --sections --apply

步驟 4：另外三個旋鈕，先預覽（還是不會寫入）。 記憶體池是六項裡唯一真的會讓遊戲跑不跑得動的，解析度挑一個你螢幕的。

Windows:

python mvp_modernize.py "〔你的遊戲資料夾〕/mvp2005.exe" --4gb --pool 128 --resolution 1920x1080

Mac / Linux:

python3 mvp_modernize.py "〔你的遊戲資料夾〕/mvp2005.exe" --4gb --pool 128 --resolution 1920x1080

步驟 5：看過它列的計畫沒問題，同一行最後加上 --apply 才真的寫。

Windows:

python mvp_modernize.py "〔你的遊戲資料夾〕/mvp2005.exe" --4gb --pool 128 --resolution 1920x1080 --apply

Mac / Linux:

python3 mvp_modernize.py "〔你的遊戲資料夾〕/mvp2005.exe" --4gb --pool 128 --resolution 1920x1080 --apply

⚠️ 照原版光碟安裝的遊戲，--pool 這一項做不到： 那種執行檔的程式碼是加密的，腳本會印「找不到記憶體池的樣態」 然後整行停下來，連 --4gb 與 --resolution 都不會被套用。 把 --pool 128 拿掉再跑一次，另外兩項照樣做得到。 為什麼，看中文版那一課。

步驟 6：開遊戲。

✅ Pass 條件

以下全部滿足：

  • 兩支腳本都印出複驗:改動的位元組剛好是預期那 N 個，其他一個都沒動 ✅
  • 遊戲開得起來，能進到主選單
  • 解析度真的變了
  • 如果你玩的是中文版：裝上你最大的那座球場，讀取條走完不跳出

❌ Fail 處理

狀況怎麼辦
腳本說「這不是 Windows 執行檔」 路徑指錯了。確認指到 mvp2005.exe 本身，不是資料夾
腳本說每一項都「本來就填好了 / 沒有需要收緊的」 那不是失敗。你那顆本來就是好的，跳到步驟 4
遊戲開不起來了 立刻還原，兩支都要，後改的先還原：

Windows:

python mvp_modernize.py "〔路徑〕/mvp2005.exe" --restore
python mvp_exe_pe.py "〔路徑〕/mvp2005.exe" --restore

Mac / Linux:

python3 mvp_modernize.py "〔路徑〕/mvp2005.exe" --restore
python3 mvp_exe_pe.py "〔路徑〕/mvp2005.exe" --restore

順序不可以反：mvp_modernize 的備份是在 mvp_exe_pe 寫完之後才留下的，記的是中間狀態。反過來做的話， 第二行會判定「這份備份跟現在這顆執行檔對不上」而停住 （檔案其實已經回到原版了，但畫面看起來像失敗）。

中文版還是跳出 池子開大一點試 --pool 256。還是不行就 完整那一課，那裡有對照實驗
畫面破圖或介面跑位 解析度往下挑一階再跑一次：步驟 4 填 3840x2160 的改成 1920x1080，本來就填 1920x1080 的改成 1600x900。 版面檔是 640×480 座標系寫的，4K 下會不會跑位本站沒驗過

📌 重點整理

  • 一句話：六個旋鈕，兩支腳本，先預覽再寫入，兩支都能還原。
  • 只有一個旋鈕真的會改變遊戲跑不跑得動： 記憶體池 64 MiB → 128 MiB。其他五項是把檔案修正確或改畫面。
  • 4GB 旗標單獨做沒有感覺，它是給記憶體池撐空間的，兩個一起做才有意義。
  • 腳本預設唯讀：不加參數只會印狀態，加了參數也只是預覽， 要再加 --apply 才會真的寫。
  • 本站沒驗的：檔頭那三項都做完的那顆在真實 Windows 上長期玩起來如何、 4K 下介面會不會跑位。（記憶體池那一項不在此列：四種大小是 Windows 與 macOS 兩邊都做過的實機測試。） 原理與逐位元組的完整說明在 執行檔上的六個旋鈕。
