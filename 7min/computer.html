七分鐘從電腦小白到可以修改模組

這一堂沒有任何前置。如果你看到「打開命令提示字元」就卡住，這一堂就是為你寫的。七分鐘之後，本站每一課的指令你都跑得動。

前置

  • 一台電腦
  • 沒了

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。

怎麼整包複製、紀錄（王朝、名單、設定）放在哪、找不到怎麼找： 看備份與還原 SOP 的「整包複製」。

👉 你要做的事

1

打開命令列。

  • Windows：按 Win，打「cmd」，按 Enter
  • Mac：按 Cmd+空白鍵，打「終端機」，按 Enter

會跳出一個黑黑的視窗，裡面有一行字跟一個游標。它就是在等你打字。打錯不會壞掉，按 Enter 才會執行。

2

搞懂「路徑」。

一句話

路徑就是一個檔案或資料夾的完整住址。本站的指令裡寫「〔你的遊戲資料夾〕」的地方，你要換成自己電腦上那個住址。

住址長這樣：

C:\Program Files (x86)\EA SPORTS\MVP Baseball 2005
/Users/〔你的名字〕/Games/MVP Baseball 2005

有空白的路徑一定要用引號包起來，不然電腦會以為是兩個東西。

3

不要用打的，用拖的。

這是最重要的一招：把資料夾直接拖進那個黑視窗，路徑會自己打出來，一個字都不會錯。

Windows 先打 cd /d、Mac 先打 cd，再打一個空白，然後把遊戲資料夾拖進去，按 Enter。你現在就「站在」那個資料夾裡了。 （Windows 的 /d 是讓它連磁碟機一起換過去，遊戲裝在 D 槽也跑得到那裡。 這一點依據的是微軟官方文件，本站還沒在裝在 D 槽的遊戲上實測。）

4

裝 Python(本站的腳本都是用它跑的)。

  • Windows：到 python.org，按最上面那顆大按鈕「Download Python install manager」下載，點兩下按「Install」。 這個新的安裝方式沒有「Add python.exe to PATH」勾選框，不用找；電腦上還沒有任何一版 Python 的話，第一次打 python 時它會自己下載最新版。 （這個新的安裝方式本站還沒在 Windows 上實測。每一步的細節、舊式安裝程式那條退路，看第 0 課操作五。）
  • Mac：較新的 macOS 本身帶著一個 python3 指令，但沒裝過「開發者工具」的 Mac，第一次打它可能會跳出要你安裝的視窗 —— 按「安裝」，裝完再打一次。 沒跳視窗也印不出版本，就照第 0 課操作五的 d 步驟，或到 python.org 下載 macOS 版。 （那個視窗本站還沒在沒裝過開發者工具的 Mac 上實測。）

裝完確認：

Windows:

python --version

Mac / Linux:

python3 --version

印出版本號就成功了，第二個數字要 7 以上（Python 3.7、3.9、3.12 都行）。印出的是 Python 2.7.x 代表版本太舊：Windows 改打 py -3 --version（py 只有 Windows 有）、Mac 改打 python3 --version 試試，哪一個印出 3.x 就用哪一個。Windows 打 python、Mac 打 python3 ——本站大多數課的指令兩種都會給你；只給 python3 的那幾課（例如2026 年的電腦怎麼跑得起 2005 年的遊戲），Windows 上請自己把開頭的 python3 換成 python；反過來，只給 python 的課，Mac 請換成 python3。

5

跑第一個真的有用的指令：檢查你的備份。

下載 mvp_check_backup.py。瀏覽器多半不會問你要存哪裡，會直接放進「下載」資料夾，所以指令要在「下載」裡打：

Windows：打開檔案總管，左邊點「下載」，點一下最上面的網址列（整條會反白），把字刪掉改打 cmd 按 Enter。開出來的是新的命令提示字元，已經停在「下載」裡，下面標 Windows 的那一行在這個新視窗打（第 3 步那個視窗停在遊戲資料夾，在那裡打會找不到腳本）。

Mac：在終端機先打這一行：

cd ~/Downloads

Windows:

python mvp_check_backup.py "〔你的遊戲資料夾〕"

Mac / Linux:

python3 mvp_check_backup.py "〔你的遊戲資料夾〕"

它只會看、不會改。這就是你的第一次成功。

✅ 怎麼知道成功了

  • 黑視窗打得開
  • --version 印得出 3.7 以上的 Python 版本
  • 備份檢查腳本跑得出結果

❌ 出錯處理

症狀怎麼辦
can't open file '…mvp_*.py' 命令視窗跟腳本不在同一個資料夾。 打開放著那個 .py 的資料夾（剛下載的話就是「下載」），在網址列打 cmd 按 Enter，用新開的視窗再跑一次（Mac 用 cd 切過去，例如 cd ~/Downloads）。 還是一樣的話，是檔名對不上：瀏覽器可能在檔名後面加了 (1)，把它改成跟指令裡一模一樣。
說找不到 pythonWindows 上用舊式安裝程式裝的話，八成是安裝時沒勾「Add python.exe to PATH」，重新安裝並勾起來；新的 Python install manager 沒有這個勾選框，照第 0 課操作五的 e 步驟檢查
印出一段 Python was not found 開頭的英文，或跳出 Microsoft Store多半是這台電腦還沒裝 Python，跳出來的是 Windows 內建的轉接捷徑，不是 Python 本身。關掉它，照上面第 4 步裝（這兩種畫面本站還沒在 Windows 上實測）
印出的是 Python 2.7.x版本太舊。Windows 改打 py -3 --version（py 只有 Windows 有），Mac 改打 python3 --version；哪一個印出 3.x，就把本站指令開頭的 python 換成它
說找不到檔案路徑打錯了。用拖的，不要用打的
路徑有空白就出錯整個路徑用雙引號包起來
視窗一閃就關掉不要雙擊 .py 檔。要先開命令列，再在裡面打指令
按下載之後，瀏覽器說檔案被擋下來、「可能有害」或「不常下載」那是瀏覽器對程式檔的預防，不代表檔案有問題。怎麼放行看第 0 課這一張卡片（這些訊息的字樣本站還沒在 Windows 上實測）

⚠️ 這一課到哪裡為止

本站所有會改你檔案的腳本，都遵守同一組規矩：批次模式不加 --apply 就只是預覽（少數腳本另有互動模式，那時要自己打 y 才會寫）、第一次寫入前會自動備份、而且都有 --restore 可以還原。

所以放心亂試。先預覽、看清楚、再決定 —— 這就是全部。
