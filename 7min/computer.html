🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站每一支工具都會自己備份它要動的那一個檔， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

👉 你要做的事

1

打開命令列。

  • Windows：按 Win，打「cmd」，按 Enter
  • Mac：按 Cmd+空白鍵，打「終端機」，按 Enter

會跳出一個黑黑的視窗，裡面有一行字跟一個游標。它就是在等你打字。打錯不會壞掉，按 Enter 才會執行。

2

搞懂「路徑」。

一句話

路徑就是一個檔案或資料夾的完整住址。本站的指令裡寫「〔你的遊戲資料夾〕」的地方，你要換成自己電腦上那個住址。

住址長這樣：

C:\Program Files (x86)\EA SPORTS\MVP Baseball 2005
/Users/〔你的名字〕/Games/MVP Baseball 2005

有空白的路徑一定要用引號包起來，不然電腦會以為是兩個東西。

3

不要用打的，用拖的。

這是最重要的一招：把資料夾直接拖進那個黑視窗，路徑會自己打出來，一個字都不會錯。

先打 cd 再打一個空白，然後把遊戲資料夾拖進去，按 Enter。你現在就「站在」那個資料夾裡了。

4

裝 Python(本站的腳本都是用它跑的)。

  • Windows：到 python.org 下載安裝。安裝時第一頁那個「Add Python to PATH」一定要打勾 —— 沒勾的話指令會找不到它
  • Mac：通常已經有了。沒有的話一樣去 python.org 下載

裝完確認：

Windows:

python --version

Mac / Linux:

python3 --version

印出版本號就成功了，第二個數字要 7 以上（Python 3.7、3.9、3.12 都行）。印出的是 Python 2.7.x 代表版本太舊：Windows 改打 py -3 --version（py 只有 Windows 有）、Mac 改打 python3 --version 試試，哪一個印出 3.x 就用哪一個。Windows 打 python、Mac 打 python3 ——本站大多數課的指令兩種都會給你；只給 python3 的那幾課（例如七分鐘調好你的執行檔），Windows 上請自己把開頭的 python3 換成 python。

5

跑第一個真的有用的指令：檢查你的備份。

下載 mvp_check_backup.py 放到桌面，然後：

Windows:

cd %USERPROFILE%\Desktop

Mac / Linux:

cd ~/Desktop

Windows:

python mvp_check_backup.py "〔你的遊戲資料夾〕"

Mac / Linux:

python3 mvp_check_backup.py "〔你的遊戲資料夾〕"

它只會看、不會改。這就是你的第一次成功。

✅ 怎麼知道成功了

  • 黑視窗打得開
  • --version 印得出 3.7 以上的 Python 版本
  • 備份檢查腳本跑得出結果

❌ 出錯處理

症狀怎麼辦
說找不到 pythonWindows 上八成是安裝時沒勾「Add Python to PATH」。重新安裝並勾起來
印出的是 Python 2.7.x版本太舊。Windows 改打 py -3 --version（py 只有 Windows 有），Mac 改打 python3 --version；哪一個印出 3.x，就把本站指令開頭的 python 換成它
說找不到檔案路徑打錯了。用拖的，不要用打的
路徑有空白就出錯整個路徑用雙引號包起來
視窗一閃就關掉不要雙擊 .py 檔。要先開命令列，再在裡面打指令

⚠️ 這一課到哪裡為止

本站所有會改你檔案的腳本，都遵守同一組規矩：批次模式不加 --apply 就只是預覽（少數腳本另有互動模式，那時要自己打 y 才會寫）、第一次寫入前會自動備份、而且都有 --restore 可以還原。

所以放心亂試。先預覽、看清楚、再決定 —— 這就是全部。
