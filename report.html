回報與下架

這一頁是本站管道資訊的單一來源。 站上其他地方（包含每一支腳本的檔頭）都指向這裡， 管道有任何變動一律以這一頁為準；法律頁第 10 節那張下架表 由檢查器 selftest_channels.py 盯著跟這裡一致， 不會出現「這頁寫這個、那頁寫那個」。

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。

怎麼整包複製、紀錄（王朝、名單、設定）放在哪、找不到怎麼找： 看備份與還原 SOP 的「整包複製」。

⚡ 你是哪一種？

  1. 教學照做卡住了 / 數字對不上 / 腳本壞了 → 看下面「回報一個問題」。 兩條管道，其中一條用 Google 帳號就能留言，不用註冊 GitHub。
  2. 你是權利人，要求本站移除內容 → 看下面「下架管道」。 三條管道，而且其中一條完全不必經過本站維護者。

回報一個問題

回報之前，先做一件事會讓事情快很多：動手的教學裡，約一半最後附有「回報範本」 （有些頁面叫「📋 回報格式」或「📋 卡住的話，照這個格式回報」），把它複製下來填一填。 裡面問的東西（你的系統、你跑了哪一行、看到什麼輸出）就是判斷問題所需要的全部資訊。 沒有那些資訊，來回問三次也解不掉；那一課沒有附範本的話，照括號裡那三項自己寫一遍就夠了。

不會從黑色視窗把字複製出來？看第 0 課的〈把黑色視窗裡的字複製出來〉那一張卡片。

toni的MVP 的留言區 要 Google 帳號（不用註冊 GitHub） 不想註冊 GitHub、或只是想問一句。這個站從 2008 年就在了
GitHub Issues 要（免費） 要貼一大段輸出、要來回追蹤的問題

⚠️ 貼回報之前，先看一眼路徑

腳本的輸出常常帶著你電腦上的完整路徑，而那裡面通常有你的使用者名稱。 例如檢查安裝的那一支，第一行就是把你打進去的路徑原樣印出來：

遊戲資料夾  C:\Users\〔你的名字〕\Games\MVP Baseball 2005

貼到公開的地方之前，把那一段改成 XXX。 本站需要的是後面的檔名、數字與雜湊值，不需要知道你叫什麼。

指紋那一支（mvp_fingerprint.py）已經預設只印資料夾名稱， 要完整路徑得自己加 --show-full-paths —— 但它是特例，其他腳本照你打的原樣印。

下架管道（Takedown）

若您是權利人並認為本站任何內容侵權， 不需要先跟維護者聯絡，以下任何一條管道都可以。 本站不會要求您先證明什麼。

管道要不要帳號要不要經過本站維護者說明
GitHub 的下架流程 依 GitHub 規定 不必 本站是 GitHub Pages 靜態頁。權利人可以直接走 GitHub 自己的下架流程，完全不必經過本站維護者，也不必等他回應。 這是本站唯一一條「維護者失聯也照樣有效」的管道。官方說明：GitHub DMCA Takedown Policy
GitHub Issues 要（免費） 要 公開的討論串，處理過程所有人看得到
toni的MVP 的留言區 要 Google 帳號（不用註冊 GitHub） 要 不想開 GitHub 帳號時走這條。留言可能需要審核， 所以不是最快的一條

📋 成立之後會發生什麼

整個站是靜態頁，刪掉一個檔就沒了 —— 個別頁面或整站可以在幾分鐘內下線，不需要跑任何流程。 本站也不會要求您先證明權利歸屬再處理。

本站的承諾（與法律頁第 10 節同一份）：

  • 收到通知後先下架、再討論 —— 不會要求您先證明什麼。
  • 目標在七日內回應。若維護者無法回應， 上表第一條（直接向 GitHub 提出）不經過他也一樣有效。
  • 下架的內容會記在更新紀錄， 寫明「下架了什麼、為什麼」，但不會寫出通知人是誰。

本站的自我約束寫在法律與版權說明： 不散布遊戲本體、不教規避防盜拷、教的是修改你自己那一份。

為什麼有這一頁

2026-08-29 之前，站上有 42 個地方各自寫死同一個 GitHub 網址 （23 個頁面、19 支腳本的檔頭註解）。那有兩個問題：

  • 管道一改要改 42 個地方，而且沒有任何東西在保證它們一致。
  • 而它們確實已經分岔了：關於那一頁的聯絡表 列了兩條（留言區＋GitHub Issues），而法律頁的下架表 原本沒有留言區那一條 —— 也就是「不用開帳號」這個唯一的無門檻管道， 只寫在其中一頁上。2026-08-29 已經補齊並對齊。 （2026-09-23 訂正：部落格留言現在要 Google 帳號才能留， 這裡說的「不用開帳號」「唯一的無門檻管道」已經不成立；上面兩張表已經照實改寫。）

現在全部指向這一頁。以後管道有任何變動，改這裡就好。

📌 重點整理

  • 一句話 回報問題與要求下架的所有管道都在這一頁，站上其他地方都指向這裡。
  • 不想註冊 GitHub 走 toni的MVP 的留言區（要 Google 帳號），回報與下架都收。
  • 權利人最強的一條 直接向 GitHub 提出 —— 不必經過本站維護者，也不必等他回應。
  • 成立之後 靜態頁刪掉一個檔就沒了，幾分鐘內可以下線，不會要求您先證明什麼； 目標七日內回應，下架紀錄不會寫出通知人是誰。
  • 本站沒驗的 GitHub 那兩條管道本站都還沒有實際走過一次， 沒辦法告訴您送出之後多久會有回應；留言區那條是從 2008 年就在用的。
