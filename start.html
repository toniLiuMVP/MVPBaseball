第 0 課

新手基本功：先學會六個基本操作

後面每一課都會用到這六件事。本來就會的人可以直接去 教學列表；不熟的請在這裡練一次， 這一課不會動到任何遊戲檔案，練壞也沒關係。

其實還有一課比這裡更早

如果你完全沒有改過遊戲檔案， 暖身課：打開一個遊戲的檔案 什麼工具都不用 —— 記事本打開遊戲資料夾裡一個純文字檔，看懂它，改壞了一定回得來。

先做那一課建立信心，再回來這裡學命令提示字元，會輕鬆很多。

👀 先看這裡：下面會出現 11 個電腦詞

底下那個橘色框是給已經懂這些字的人看的。 如果你看到「網址列」「副檔名」會愣一下，那不是你的問題 —— 這張表把它們一次講完，每個一句話。看完再往下，就都看得懂了。

這個字就是這個意思
資料夾 裝東西的箱子。點兩下會打開，裡面還可以有別的箱子。
檔案總管 Windows 上用來翻箱子的那個視窗。Mac 上叫「Finder」， 就是最左邊那個藍色笑臉。
網址列 你以為它只在 Chrome 裡？檔案總管上面那條也是 —— 它顯示你現在在哪個箱子裡。那條可以打字。
路徑 箱子的地址。像 C:\遊戲\MVP —— 從最外面一層一層寫到裡面。
捷徑 桌面上那個有小箭頭的圖示。它不是遊戲本體，是指向遊戲的路標。
副檔名 檔名最後那一小截，例如 .txt、.big。 它告訴電腦這是什麼種類的檔。
.exe 一種副檔名，意思是「這個檔案是一個程式，點兩下會執行」。 遊戲本體就是 mvp2005.exe。
命令提示字元 一個只能打字的黑色視窗。不用滑鼠，你打一行字、按 Enter，電腦就做一件事。 Mac 上叫「終端機」。
cmd 命令提示字元的名字。在檔案總管的網址列打這三個字母按 Enter，它就會開在那個資料夾。
Enter 鍵盤右邊那顆大按鍵（有時候印著 ⏎）。在黑視窗裡代表「我打完了，做吧」。
Python 一個免費的程式，本站的工具需要它才能跑。裝一次就好，以後都不用再管。 七分鐘電腦課裡有手把手的裝法。

課程裡還會遇到更多專有名詞，常見的那些收在名詞小教室：中英對照加一句話解釋（不用開 JavaScript 也能看）。

⚠️ 這一課不會動到任何遊戲檔案，練壞也沒關係。 真的還是卡住的話，先去做暖身課 —— 那一課連黑視窗都不用開。

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們平常跟遊戲檔混在同一個資料夾裡；遊戲裝在 Program Files 底下時，Windows 可能把它們轉存到別處，怎麼查）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站會動到遊戲檔的工具都會自己備份它要動的那一個檔 （純檢查用的那幾支不寫檔，沒有備份，也不需要還原）， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

⚡ 只想趕快做完？照這五步（用到上面那張表的字）

  1. 找到遊戲資料夾：對桌面上的遊戲捷徑按右鍵 →「開啟檔案位置」。 同一層同時看得到 mvp2005.exe 跟一個叫 data 的資料夾，兩個都有才是對的。 沒有捷徑就把這一行貼進檔案總管的網址列： 
    C:\Program Files (x86)\EA SPORTS
  2. 在那個資料夾的網址列把字刪掉、改打 cmd 按 Enter， 開出來的命令提示字元已經停在那個資料夾。 Mac 是按 ⌘ Cmd + 空白鍵，輸入「終端機」。
  3. 把副檔名打開：隨便開一個資料夾視窗 →「檢視」→「顯示」→ 勾「副檔名」。 不開這個，記事本會把腳本存成 xxx.py.txt。
  4. 要填路徑時不要用打的：指令打到需要路徑的位置、空一格、游標停著不要按 Enter， 再把檔案拖進視窗放開。
  5. 確認電腦有沒有 Python（Windows 用第一行、Mac 用第二行）。印出來開頭是 3、第二個數字 7 以上就完課（印出 2.7.x 不算，往下看操作五）。 
    python --version
    python3 --version

第六件事沒有指令：改任何檔案之前先複製一份放旁邊，檔名加 .bak。 這一課本身不會動到任何遊戲檔案，練壞也沒關係。 想知道每一步為什麼這樣做，往下讀；只想複習，跳到📌 重點整理。

📱 在手機上看、到電腦上做

  • 最省事：把這一頁的網址傳給自己（例如寄 email 給自己，或用 LINE 傳給自己），到電腦上點開。
  • 要自己打網址的話，只打首頁就好，再從首頁點進來：
https://toniliumvp.github.io/MVPBaseball/

網址中間的 MVPBaseball，M、V、P、B 四個字母要大寫。 打錯的話會看到 GitHub 的「Site not found」 —— 那不是本站關了，是網址打錯，回來把大小寫改對就好。

先認識幾個名詞

命令提示字元一個只有文字的視窗：你打字給電腦，電腦回你文字。Mac 上叫「終端機」。本站的指令都打在這裡。
路徑檔案在電腦裡的完整位置，像門牌號碼。例如 C:\Games\MVP\data\frontend\ingame.big。
副檔名檔名最後那一小段，例如 .big、.py。Windows 預設把它藏起來，這會害你存錯檔。
指令你打進命令提示字元的那一行字。本站所有指令都可以整行複製貼上； 帶 〔…〕、<…>，或寫著「你的遊戲資料夾」的地方，要先換成你自己的（多半是路徑；括號連同裡面的字一起換掉）。 用拖曳的話，如果那一段外面剛好包著一對引號（像 "〔你的遊戲資料夾〕"），把引號連同那一段一起刪掉，再把資料夾或檔案拖進來。
備份動手前先複製一份原始檔留著，做錯了就把它換回去。本站會動到遊戲檔的工具都會自動幫你做這件事。

操作零：找到你的遊戲資料夾

這是所有教學的第一步，而本站以前沒教

每一課的第一個動作都是「打開遊戲資料夾」。 但遊戲不一定裝在你以為的地方 —— 而且路徑打錯是新手最常卡住的第一關。 這一節 2026-08-26 補上。

為什麼要學：後面每一課都要用到它。找一次，記起來。

怎麼找（Windows，三種方法擇一）

  1. 從桌面捷徑找（最快）： 對桌面上的遊戲捷徑按右鍵 → 選「開啟檔案位置」。 檔案總管會直接跳到遊戲資料夾。 （如果跳到的還是捷徑，再按一次右鍵→開啟檔案位置。）
  2. 從開始功能表找：按 ⊞ Win 打「MVP」， 在搜尋結果上按右鍵 → 「開啟檔案位置」。
  3. 直接去常見的安裝位置：檔案總管網址列貼上這一行按 Enter： 
    C:\Program Files (x86)\EA SPORTS
    舊機器或 32 位元系統可能是 C:\Program Files\EA SPORTS； 自己改過安裝位置的話這一招沒用，請用前兩種。

怎麼確認找對了：那個資料夾裡同一層要看得到 mvp2005.exe 跟一個叫 data 的資料夾。 兩個都有才是對的。

找到之後，把路徑複製起來

在檔案總管的網址列點一下（整條會反白），按 Ctrl+C。 後面每一課要你「貼上遊戲資料夾路徑」時就是貼這個。

Mac：在 Finder 裡對資料夾按右鍵，按住 ⌥ Option， 選單會變成「拷貝……為路徑名稱」。

⚠️ 一個常見的誤會：Steam / Origin / EA app 的遊戲不在這裡。 MVP Baseball 2005 是 2005 年的光碟遊戲，沒有在那些平台上。 如果你找不到，先確認你是用光碟安裝的。

操作一：打開命令提示字元

為什麼要學：每一課的指令都在這裡打。

W
Windows：三種方法，會一種就好

1鍵盤法（最快）：按住 ⊞ Win 不放，再按一下 R，左下角跳出小視窗，輸入 cmd 三個字母，按 Enter。

2搜尋法：按 ⊞ Win 直接打字， 輸入「命令提示字元」，在搜尋結果上點一下。

3資料夾法（最省事）：用檔案總管打開你要工作的資料夾， 點一下最上面的網址列（整條會反白），把裡面的字刪掉改打 cmd，按 Enter。 開出來的視窗已經停在那個資料夾，可以少打一個指令。

M
Mac：打開「終端機」

1按 ⌘ Cmd + 空白鍵，畫面中央跳出搜尋框。

2輸入「終端機」（或 Terminal），按 Enter。

你會看到

一個黑色或白色的文字視窗，最後一行結尾有個閃爍的方塊或底線 —— 那是游標，代表它在等你打字。

如果沒看到
  • Windows 找不到「命令提示字元」→ 用上面的鍵盤法：按住 ⊞ Win 再按 R，打 cmd 按 Enter。
  • 那一行開頭多了 PS（像 PS C:\Users\〔你的名字〕>）→ 你開到的是 PowerShell（Win 11 的「終端機」預設就是開這個）。 直接打 cmd 按 Enter，同一個視窗就會換成命令提示字元，開頭的 PS 會消失。 （這個切換本站還沒在 Windows 上實測。）
  • 視窗一閃就消失 → 那不是命令提示字元，你點到了別的檔案，重來一次。

Windows 還有另一個黑視窗：PowerShell

本站大多數的課用「命令提示字元」就夠了，但有幾課的指令只有 PowerShell 有 —— 例如看檔案開頭那幾個位元組要用的 Format-Hex，命令提示字元裡根本沒有這個東西。 它們是兩個不同的視窗，不是同一個。

分辨方法：PowerShell 那一行的開頭有 PS，命令提示字元沒有。 做完只用 PowerShell 的那幾課，回到其他課之前，先打 cmd 按 Enter， 或重開一個命令提示字元。

怎麼開（兩種會一種就好）：

  • 按住 ⊞ Win 不放，再按一下 R， 輸入 powershell，按 Enter。
  • 按 ⊞ Win 直接打字，輸入「PowerShell」，在搜尋結果上點一下。

還有版本要分：Windows 10／11 內建的那個叫「Windows PowerShell」， 版本是 5.1；自己另外裝的叫 PowerShell 7，指令名字是 pwsh。 兩種的參數寫法有出入，各課會分開寫。要知道自己開的是哪一種，就打這一行：

$PSVersionTable.PSVersion

印出來的 Major 是 5 就是內建的那個 5.1，是 7 就是自己裝的那一版。 Mac 沒有這個分別，終端機就是終端機。 ⚠️ 這一段的版本差異依據的是微軟官方文件，還沒在 Windows 上實測。

📋 回報時會用到：把黑色視窗裡的字複製出來

  1. 等腳本跑完，最後一行又出現可以打字的游標，再動手。
  2. 用滑鼠從要的第一個字按住，拖到最後一個字再放開，那一段字會反白。
  3. 按一下滑鼠右鍵，或按 Ctrl+C，就複製起來了； 到要回報的地方再貼上。Mac 反白之後按 ⌘ Cmd+C。

兩個容易踩到的地方：

  • 腳本還在跑的時候，不要在視窗裡面點。Windows 視窗最上面的標題列如果出現「選取」兩個字， 代表程式被暫停了，按 Esc 它就會繼續。
  • 沒有反白就按 Ctrl+C，會把還在跑的腳本停掉。 Mac 的 Control+C 也是「停掉」，不是複製。

⚠️ 這一張卡片的按鍵與畫面字樣是 Windows、Mac 的一般行為，還沒在 Windows 上實測。 要回報去哪裡，看回報與下架。

操作二：取得檔案的完整路徑（不用手打）

為什麼要學：指令需要檔案路徑。路徑很長又容易打錯，用拖曳最保險。

a先在命令提示字元把指令打到需要路徑的位置，打一個空格，游標停著不要按 Enter。

b用檔案總管（Mac 用 Finder）找到那個檔案。

c用滑鼠按住檔案不放，拖到命令提示字元視窗上放開。

d路徑會自動填進去（通常還會自動加引號），這時再按 Enter。

你會看到

指令後面自動出現一長串路徑，例如 "C:\Program Files (x86)\EA SPORTS\MVP Baseball 2005\data\frontend\ingame.big"。

如果拖曳沒反應

手動打也可以，但路徑前後一定要各加一個半形雙引號。 路徑裡有空格（例如 Program Files）時，沒有引號電腦會以為你在講好幾個檔案。

操作三：讓 Windows 顯示副檔名

為什麼要學：Windows 預設把副檔名藏起來。你用記事本存腳本時會存成 xxx.py.txt 而畫面上看起來一模一樣，然後指令就跑不動。這是新手最常卡住的地方。

a隨便打開一個資料夾視窗。

bWindows 11：點上方「檢視」→「顯示」→ 勾選「副檔名」。

cWindows 10：點上方「檢視」頁籤 → 在右邊勾選「副檔名」。

你會看到

資料夾裡的檔名後面開始出現 .big、.txt、.exe 這些尾巴。

Mac 沒這個問題；若 Finder 也藏了副檔名，到「Finder → 設定 → 進階」勾「顯示所有檔案副檔名」。

操作四：備份與還原的觀念

為什麼要學：改遊戲檔案唯一真正的保險就是備份。

  • 改任何檔案之前，先複製一份放旁邊，檔名加 .bak（例如 ingame.big.bak）。
  • 本站會動到遊戲檔的工具會自動做這件事，還提供一行指令還原（--restore）—— 純檢查用的那幾支不寫檔，也就沒有備份與還原。
  • 手動還原也很簡單：刪掉改壞的檔，把備份檔改名回原檔名。本站工具留下的備份多半不叫 .bak， 而是那一課自己的尾巴（例如 .hudcolorbak、.speedbak）—— 完整對照表在備份與還原 SOP。
  • 備份只有一份時，第二次修改前先把上一次的成果另存，不然還原會退回更早的版本。

操作五：安裝 Python（跑教學腳本用）

為什麼要學：本站的自動化工具都是 Python 小程式，零相依、附完整原始碼。

先確認電腦有沒有：打開命令提示字元，複製貼上（Windows 用第一行，Mac 用第二行），按 Enter。

python --version
python3 --version
你會看到

類似 Python 3.11.4 的一行字。開頭是 3、第二個數字 7 以上就可以用（3.7、3.9、3.12 都行；2.7.x 不算）。有了就完課！

如果沒有

aWindows：瀏覽器開 python.org → 點 Downloads → 按最上面那顆大按鈕「Download Python install manager」下載。（Mac 看 d。）

b下載好的檔案點兩下，在跳出的視窗按「Install」。 這個新的安裝方式沒有「Add python.exe to PATH」那個勾選框，不用找。

c裝完把命令提示字元關掉重開（不重開抓不到），再跑一次上面的指令確認。 電腦上如果還沒有任何一版 Python，第一次打 python 時它會自己下載最新版，要等一下。 中途如果用英文問你問題（句子後面帶著 [Y/n] 或 [y/N]），每一題直接按 Enter， 就是選大寫的那個預設答案。其中問要不要把一個資料夾加進 PATH 的那一題是選用的： 本站教的 Windows 指令用的是 python 和 py，這兩個名字都用不到那個資料夾。

⚠️ a～c 這個新的安裝方式（Python install manager）依據的是 Python 官方文件與它公開的原始碼， 還沒在 Windows 上實測；按鈕在中文 Windows 上顯示成什麼字，也還沒核對。

dMac：執行 xcode-select --install，跳出視窗按「安裝」即可。

eWindows 打 python 卻跳出 Microsoft Store，或印出一段 Python was not found 開頭的英文 → 多半代表這台電腦還沒裝 Python，跳出來的是 Windows 內建的轉接捷徑，不是 Python 本身。關掉它，照 a 步驟裝。 已經照 a～c 裝好了，打 python 還是這樣，或說它「不是內部或外部命令」：按開始，搜尋「管理應用程式執行別名」（英文介面叫 Manage app execution aliases）， 確認「Python (default)」那幾個開關是開著的。 （這兩種畫面和這個開關，本站都還沒在 Windows 上實測；開關的做法出自 Python 官方文件的排錯說明。）

f印出的是 Python 2.7.x → 版本太舊（本站腳本要 3.7 以上）。 這有可能是兩個版本都裝了，只是 python 這個名字指到舊的那個 —— Windows 先打 py -3 --version 試試（py 只有 Windows 有）； Mac 則是打上面第二行的 python3 --version。 哪一個印出 3.x，就把本站指令開頭的 python 換成它 （例如 py -3 mvp_hide_runner_speed.py）；兩個都沒有才照 a 步驟另外裝一份。

g退路：a～c 走不通，或你想用舊式的安裝程式 → a 步驟那顆大按鈕下面有一行小字 「Or get the standalone installer for Python …」，點後面的版本號下載。 執行時，安裝畫面最下面的勾選框「Add python.exe to PATH」一定要先打勾， 再按 Install Now；裝完一樣做 c。 Python 官方文件寫明，這種安裝程式從 3.14 起列為淘汰，3.16 以後的版本就不再提供。 （這條退路本站還沒在 Windows 上實測。）

按下載之後，瀏覽器說檔案被擋下來了？

本站的腳本大多是 .py 這一類「程式檔」。瀏覽器對程式檔比較嚴格， 在剛認識的網站下載時，可能先把它擋下來，說它「可能有害」或「不常下載」。 這是瀏覽器對檔案類型的預防，不代表檔案有問題。

  • Edge：在下載清單那一項按「…」，選「保留」；如果又跳出一個確認框，按「顯示更多」，選「仍要保留」。
  • Chrome：在下載清單那一項找「保留」或「仍要下載」。
  • 另一個做法：對下載按鈕按右鍵，選「另存連結為…」，自己挑一個存放的地方。 Edge 的官方說明寫著，用這個方法存，就不會因為「這是程式檔」被擋下來。

⚠️ 上面這些訊息和按鈕的字樣，本站還沒在 Windows 上實測，你的畫面上可能叫法略有不同。

六個基本功練熟了，後面就是照著打字而已

📌 重點整理

  • 一句話 第 0 課先把後面每一課都會用到的六個基本操作練一次，這一課不會動到任何遊戲檔案，練壞也沒關係。
  • 其實還有一課更早 完全沒改過遊戲檔案的人，先去做暖身課「打開一個遊戲的檔案」，什麼工具都不用，記事本開一個純文字檔看懂它，改壞了一定回得來，建立信心之後再回來學命令提示字元會輕鬆很多。
  • 操作零是 2026-08-26 才補上的 每一課的第一個動作都是「打開遊戲資料夾」，而本站以前沒教。找法是對桌面捷徑按右鍵選「開啟檔案位置」，或到 C:\Program Files (x86)\EA SPORTS。確認找對了的條件是同一層同時看得到 mvp2005.exe 跟一個叫 data 的資料夾，兩個都有才算。另外 MVP Baseball 2005 是 2005 年的光碟遊戲，Steam、Origin、EA app 上都沒有。
  • 新手最常卡住的兩關 一是路徑打錯，二是 Windows 預設把副檔名藏起來，用記事本存腳本會存成 xxx.py.txt 而畫面上看起來一模一樣，然後指令就跑不動。所以先到「檢視」把副檔名打開。
  • 路徑用拖的不要用打的 指令打到需要路徑的位置後空一格、游標停著不要按 Enter，把檔案拖進視窗放開，路徑會自動填進去（通常還會自動加引號）。真要手打的話，路徑前後一定要各加一個半形雙引號，不然遇到 Program Files 這種含空格的路徑，電腦會以為你在講好幾個檔案。指令裡帶 〔…〕、<…>，或寫著「你的遊戲資料夾」的地方，都要換成你自己的（多半是路徑）；用拖的話，如果那一段外面剛好包著一對引號，把引號連同那一段一起刪掉再拖進來。
  • 備份的觀念，還有一個容易漏的陷阱 改任何檔案之前先複製一份加 .bak，本站會動到遊戲檔的工具會自動做並提供 --restore 一行還原（它們留的備份多半不叫 .bak，而是那一課自己的尾巴）。但備份只有一份時，第二次修改前要先把上一次的成果另存，不然還原會退回更早的版本。
  • Python 要開頭是 3、第二個數字 7 以上 python --version（Mac 用 python3）印出來開頭是 3、第二個數字 7 以上才能用（2.7.x 不算）。Windows 要裝的話，按 python.org 最上面那顆「Download Python install manager」，點兩下按 Install —— 這個新的安裝方式沒有「Add python.exe to PATH」勾選框；改用大按鈕下面那行小字的舊式安裝程式才有，那時一定要先打勾。裝完要把命令提示字元關掉重開才抓得到。打 python 跳出 Microsoft Store 或印出 Python was not found，多半代表還沒裝 —— 那是 Windows 內建的轉接捷徑，不是 Python 本身，關掉去 python.org 裝；印出 2.7 就改用 py -3（只有 Windows 有）或 python3。
  • 本站沒驗的 這一課本身沒有量測任何數字，頁面自己標了保留的有下面這幾處。一是常見安裝位置那條路徑，舊機器或 32 位元系統可能是 C:\Program Files\EA SPORTS，自己改過安裝位置的話這一招完全沒用，要改用前兩種找法；二是 python 印出 2.7 時，頁面寫的是「有可能是兩個版本都裝了，只是這個名字指到舊的那個」，那也是可能性，要靠 py -3 或 python3 實際試出來；三是操作一補的 PowerShell 那一段（內建 5.1 與自己裝的 7 之差、$PSVersionTable.PSVersion 這行看版本的指令）依據的是微軟官方文件，還沒在 Windows 上實測；四是 Windows 上的幾段操作畫面也還沒實測：操作五新的安裝方式（Python install manager）與舊式安裝程式那條退路、打 python 跳出 Microsoft Store 或印出 Python was not found 的畫面、開頭是 PS 時打 cmd 切回命令提示字元、從黑色視窗把字複製出來的按鍵，以及下載被瀏覽器擋下來時的按鈕字樣。
