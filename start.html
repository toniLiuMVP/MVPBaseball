第 0 課

新手基本功：先學會六個基本操作

後面每一課都會用到這六件事。本來就會的人可以直接去 教學列表；不熟的請在這裡練一次， 這一課不會動到任何遊戲檔案，練壞也沒關係。

其實還有一課比這裡更早

如果你完全沒有改過遊戲檔案， 暖身課：打開一個遊戲的檔案 什麼工具都不用 —— 記事本打開遊戲資料夾裡一個純文字檔，看懂它，改壞了一定回得來。

先做那一課建立信心，再回來這裡學命令提示字元，會輕鬆很多。

👀 先看這裡：下面會出現 11 個電腦詞

底下那個橘色框是給已經懂這些字的人看的。 如果你看到「網址列」「副檔名」會愣一下,那不是你的問題 —— 這張表把它們一次講完,每個一句話。看完再往下,就都看得懂了。

這個字就是這個意思
資料夾 裝東西的箱子。點兩下會打開,裡面還可以有別的箱子。
檔案總管 Windows 上用來翻箱子的那個視窗。Mac 上叫「Finder」, 就是最左邊那個藍色笑臉。
網址列 你以為它只在 Chrome 裡?檔案總管上面那條也是 —— 它顯示你現在在哪個箱子裡。那條可以打字。
路徑 箱子的地址。像 C:\遊戲\MVP —— 從最外面一層一層寫到裡面。
捷徑 桌面上那個有小箭頭的圖示。它不是遊戲本體,是指向遊戲的路標。
副檔名 檔名最後那一小截,例如 .txt、.big。 它告訴電腦這是什麼種類的檔。
.exe 一種副檔名,意思是「這個檔案是一個程式,點兩下會執行」。 遊戲本體就是 mvp2005.exe。
命令提示字元 一個只能打字的黑色視窗。不用滑鼠,你打一行字、按 Enter,電腦就做一件事。 Mac 上叫「終端機」。
cmd 命令提示字元的名字。在檔案總管的網址列打這三個字母按 Enter,它就會開在那個資料夾。
Enter 鍵盤右邊那顆大按鍵(有時候印著 ⏎)。在黑視窗裡代表「我打完了,做吧」。
Python 一個免費的程式,本站的工具需要它才能跑。裝一次就好,以後都不用再管。 七分鐘電腦課裡有手把手的裝法。

⚠️ 這一課不會動到任何遊戲檔案,練壞也沒關係。 真的還是卡住的話,先去做暖身課 —— 那一課連黑視窗都不用開。

🛟 動手之前：先完整備份整個遊戲資料夾

把整個遊戲資料夾複製一份到別的地方， 包括裡面存放紀錄的資料夾。不要挑檔案，整包複製最省事也最保險。

「紀錄」是指這些（它們跟遊戲檔混在同一個資料夾裡）：

  • Support\MVP Baseball 2005\ —— 遊戲自己建的， 裡面是設定（MVPOptions_Options.sav）與手把設定 （controller.cfg）。剛安裝好時沒有這個資料夾，玩過才出現。
  • 王朝、老闆模式、名單與玩家檔案的存檔（*_Franchise.sav、 *_Owner Mode.sav、*_Rosters.sav、*_Profile.sav）—— 沒有固定的資料夾名，你或你裝的模組包叫它什麼它就叫什麼。找不到就用這一行找：
dir /s /b "〔你的遊戲資料夾〕\*.sav"
find "〔你的遊戲資料夾〕" -name "*.sav"

上面第一行 Windows、第二行 Mac。 本站會動到遊戲檔的工具都會自己備份它要動的那一個檔 （純檢查用的那幾支不寫檔，沒有備份，也不需要還原）， 但那只保得住那一個檔 —— 整包備份保的是「你玩到現在的一切」。 完整做法看備份與還原 SOP。

⚡ 只想趕快做完？照這五步（用到上面那張表的字）

  1. 找到遊戲資料夾：對桌面上的遊戲捷徑按右鍵 →「開啟檔案位置」。 同一層同時看得到 mvp2005.exe 跟一個叫 data 的資料夾，兩個都有才是對的。 沒有捷徑就把這一行貼進檔案總管的網址列： 
    C:\Program Files (x86)\EA SPORTS
  2. 在那個資料夾的網址列把字刪掉、改打 cmd 按 Enter， 開出來的命令提示字元已經停在那個資料夾。 Mac 是按 ⌘ Cmd + 空白鍵，輸入「終端機」。
  3. 把副檔名打開：隨便開一個資料夾視窗 →「檢視」→「顯示」→ 勾「副檔名」。 不開這個，記事本會把腳本存成 xxx.py.txt。
  4. 要填路徑時不要用打的：指令打到需要路徑的位置、空一格、游標停著不要按 Enter， 再把檔案拖進視窗放開。
  5. 確認電腦有沒有 Python（Windows 用第一行、Mac 用第二行）。印出來開頭是 3、第二個數字 7 以上就完課（印出 2.7.x 不算，往下看操作五）。 
    python --version
    python3 --version

第六件事沒有指令：改任何檔案之前先複製一份放旁邊，檔名加 .bak。 這一課本身不會動到任何遊戲檔案，練壞也沒關係。 想知道每一步為什麼這樣做，往下讀；只想複習，跳到📌 重點整理。

先認識幾個名詞

命令提示字元一個只有文字的視窗：你打字給電腦，電腦回你文字。Mac 上叫「終端機」。本站的指令都打在這裡。
路徑檔案在電腦裡的完整位置，像門牌號碼。例如 C:\Games\MVP\data\frontend\ingame.big。
副檔名檔名最後那一小段，例如 .big、.py。Windows 預設把它藏起來，這會害你存錯檔。
指令你打進命令提示字元的那一行字。本站所有指令都可以整行複製貼上；只有帶 〔…〕 的那幾行要先把括號連同裡面的字換成你自己的路徑。
備份動手前先複製一份原始檔留著，做錯了就把它換回去。本站會動到遊戲檔的工具都會自動幫你做這件事。

操作零：找到你的遊戲資料夾

這是所有教學的第一步，而本站以前沒教

每一課的第一個動作都是「打開遊戲資料夾」。 但遊戲不一定裝在你以為的地方 —— 而且路徑打錯是新手最常卡住的第一關。 這一節 2026-08-26 補上。

為什麼要學：後面每一課都要用到它。找一次，記起來。

怎麼找（Windows，三種方法擇一）

  1. 從桌面捷徑找（最快）： 對桌面上的遊戲捷徑按右鍵 → 選「開啟檔案位置」。 檔案總管會直接跳到遊戲資料夾。 （如果跳到的還是捷徑，再按一次右鍵→開啟檔案位置。）
  2. 從開始功能表找：按 ⊞ Win 打「MVP」， 在搜尋結果上按右鍵 → 「開啟檔案位置」。
  3. 直接去常見的安裝位置：檔案總管網址列貼上這一行按 Enter： 
    C:\Program Files (x86)\EA SPORTS
    舊機器或 32 位元系統可能是 C:\Program Files\EA SPORTS； 自己改過安裝位置的話這一招沒用，請用前兩種。

怎麼確認找對了：那個資料夾裡同一層要看得到 mvp2005.exe 跟一個叫 data 的資料夾。 兩個都有才是對的。

找到之後，把路徑複製起來

在檔案總管的網址列點一下（整條會反白），按 Ctrl+C。 後面每一課要你「貼上遊戲資料夾路徑」時就是貼這個。

Mac：在 Finder 裡對資料夾按右鍵，按住 ⌥ Option， 選單會變成「拷貝……為路徑名稱」。

⚠️ 一個常見的誤會：Steam / Origin / EA app 的遊戲不在這裡。 MVP Baseball 2005 是 2005 年的光碟遊戲，沒有在那些平台上。 如果你找不到，先確認你是用光碟安裝的。

操作一：打開命令提示字元

為什麼要學：每一課的指令都在這裡打。

W
Windows：三種方法，會一種就好

1鍵盤法（最快）：按住 ⊞ Win 不放，再按一下 R，左下角跳出小視窗，輸入 cmd 三個字母，按 Enter。

2搜尋法：按 ⊞ Win 直接打字， 輸入「命令提示字元」，在搜尋結果上點一下。

3資料夾法（最省事）：用檔案總管打開你要工作的資料夾， 點一下最上面的網址列（整條會反白），把裡面的字刪掉改打 cmd，按 Enter。 開出來的視窗已經停在那個資料夾，可以少打一個指令。

M
Mac：打開「終端機」

1按 ⌘ Cmd + 空白鍵，畫面中央跳出搜尋框。

2輸入「終端機」（或 Terminal），按 Enter。

你會看到

一個黑色或白色的文字視窗，最後一行結尾有個閃爍的方塊或底線 —— 那是游標，代表它在等你打字。

如果沒看到
  • Windows 找不到「命令提示字元」→ 改搜尋 cmd 或「終端機」（Win 11 換過名字）。
  • 視窗一閃就消失 → 那不是命令提示字元，你點到了別的檔案，重來一次。

Windows 還有另一個黑視窗：PowerShell

本站大多數的課用「命令提示字元」就夠了，但有幾課的指令只有 PowerShell 有 —— 例如看檔案開頭那幾個位元組要用的 Format-Hex，命令提示字元裡根本沒有這個東西。 它們是兩個不同的視窗，不是同一個。

怎麼開（兩種會一種就好）：

  • 按住 ⊞ Win 不放，再按一下 R， 輸入 powershell，按 Enter。
  • 按 ⊞ Win 直接打字，輸入「PowerShell」，在搜尋結果上點一下。

還有版本要分：Windows 10／11 內建的那個叫「Windows PowerShell」， 版本是 5.1；自己另外裝的叫 PowerShell 7，指令名字是 pwsh。 兩種的參數寫法有出入，各課會分開寫。要知道自己開的是哪一種，就打這一行：

$PSVersionTable.PSVersion

印出來的 Major 是 5 就是內建的那個 5.1，是 7 就是自己裝的那一版。 Mac 沒有這個分別，終端機就是終端機。 ⚠️ 這一段的版本差異依據的是微軟官方文件，還沒在 Windows 上實測。

操作二：取得檔案的完整路徑（不用手打）

為什麼要學：指令需要檔案路徑。路徑很長又容易打錯，用拖曳最保險。

a先在命令提示字元把指令打到需要路徑的位置，打一個空格，游標停著不要按 Enter。

b用檔案總管（Mac 用 Finder）找到那個檔案。

c用滑鼠按住檔案不放，拖到命令提示字元視窗上放開。

d路徑會自動填進去（通常還會自動加引號），這時再按 Enter。

你會看到

指令後面自動出現一長串路徑，例如 "C:\Program Files (x86)\EA SPORTS\MVP Baseball 2005\data\frontend\ingame.big"。

如果拖曳沒反應

手動打也可以，但路徑前後一定要各加一個半形雙引號。 路徑裡有空格（例如 Program Files）時，沒有引號電腦會以為你在講好幾個檔案。

操作三：讓 Windows 顯示副檔名

為什麼要學：Windows 預設把副檔名藏起來。你用記事本存腳本時會存成 xxx.py.txt 而畫面上看起來一模一樣，然後指令就跑不動。這是新手最常卡住的地方。

a隨便打開一個資料夾視窗。

bWindows 11：點上方「檢視」→「顯示」→ 勾選「副檔名」。

cWindows 10：點上方「檢視」頁籤 → 在右邊勾選「副檔名」。

你會看到

資料夾裡的檔名後面開始出現 .big、.txt、.exe 這些尾巴。

Mac 沒這個問題；若 Finder 也藏了副檔名，到「Finder → 設定 → 進階」勾「顯示所有檔案副檔名」。

操作四：備份與還原的觀念

為什麼要學：改遊戲檔案唯一真正的保險就是備份。

  • 改任何檔案之前，先複製一份放旁邊，檔名加 .bak（例如 ingame.big.bak）。
  • 本站會動到遊戲檔的工具會自動做這件事，還提供一行指令還原（--restore）—— 純檢查用的那幾支不寫檔，也就沒有備份與還原。
  • 手動還原也很簡單：刪掉改壞的檔，把備份檔改名回原檔名。本站工具留下的備份多半不叫 .bak， 而是那一課自己的尾巴（例如 .hudcolorbak、.speedbak）—— 完整對照表在備份與還原 SOP。
  • 備份只有一份時，第二次修改前先把上一次的成果另存，不然還原會退回更早的版本。

操作五：安裝 Python（跑教學腳本用）

為什麼要學：本站的自動化工具都是 Python 小程式，零相依、附完整原始碼。

先確認電腦有沒有：打開命令提示字元，複製貼上（Windows 用第一行，Mac 用第二行），按 Enter。

python --version
python3 --version
你會看到

類似 Python 3.11.4 的一行字。開頭是 3、第二個數字 7 以上就可以用（3.7、3.9、3.12 都行；2.7.x 不算）。有了就完課！

如果沒有

a瀏覽器開 python.org → 點 Downloads → 按黃色大按鈕下載。

b執行安裝檔。最重要的一步：安裝畫面最下面的勾選框 「Add python.exe to PATH」一定要先打勾，再按 Install Now。

c裝完把命令提示字元關掉重開（不重開抓不到），再跑一次上面的指令確認。

dMac：執行 xcode-select --install，跳出視窗按「安裝」即可。

eWindows 跳出 Microsoft Store 頁面 → 那是假的，關掉，照 a 步驟裝真的。

f印出的是 Python 2.7.x → 版本太舊（本站腳本要 3.7 以上）。 這有可能是兩個版本都裝了，只是 python 這個名字指到舊的那個 —— Windows 先打 py -3 --version 試試（py 只有 Windows 有）； Mac 則是打上面第二行的 python3 --version。 哪一個印出 3.x，就把本站指令開頭的 python 換成它 （例如 py -3 mvp_hide_runner_speed.py）；兩個都沒有才照 a 步驟另外裝一份。

六個基本功練熟了，後面就是照著打字而已
